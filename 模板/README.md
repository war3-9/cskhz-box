# 默认模板

`游戏图标.boxtemplate`（122×122、5 层）和 `商城图标.boxtemplate`（300×300、6 层）是用户提供的默认模板，直接嵌入 EXE，不能在软件内删除。`defaults.json` 固定其文件与 ID，缺失文件或 ID 不符会中止构建。保留源文件、完整图层和图片字节；同 ID 的用户存储副本只在列表隐藏，不删除数据。

在超时空盒子完成作品后，点击“模板”中的“保存为模板”，再点击模板卡片上的“导出初始模板”图标，将 `.boxtemplate` 文件保存到本目录。

在项目根目录运行 `pwsh -NoProfile -File scripts/build-desktop.ps1`，本目录中的模板及真实预览会写入压缩素材包，并嵌入 EXE。素材包不加密。新安装的用户无需导入文件即可在“模板”中查看与使用“初始模板”。

模板保留画布大小、完整图层、文字效果和用户图片；内置素材使用当前素材包的引用。打包时校验模板格式及引用，失败会终止构建。不要仅放 PNG，PNG 没有图层信息。
